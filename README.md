# מסע הקוביות · מקצוע אחד

משחק מיפוי ידע לתלמידים של [z-school](https://z-school.co.il), בגרסה שבה
**בוחרים מקצוע אחד** (עברית, מתמטיקה או אנגלית) ומשחקים רק אותו.

**▶ לשחק: https://cube-quest-subject.vercel.app**

הגרסה המלאה, שלושת המקצועות ברצף: <https://cube-quest-snowy.vercel.app>
(ריפו `ZSchool-contact/cube-quest`).

## מה ההבדל מהגרסה המלאה

זה **אותו משחק בדיוק**. ההבדל היחיד הוא שורה אחת ב-`<head>`:
`window.CQ_SUBJECT_PICK=true`. היא מציגה בחירת מקצוע במסך הפתיחה ומשאירה
במסלול רק את עולמות המקצוע שנבחר, ואחריהם את עולם הבונוס.

| מקצוע | עולמות |
|---|---|
| עברית | 1–2, ואז בונוס |
| מתמטיקה | 3–5, ואז בונוס |
| אנגלית | 6–7, ואז בונוס (מכיתה ג׳) |

העולמות הם העולמות המקוריים של המקצוע, ולכן המדידה זהה לגרסה המלאה.
הדוח נשמר לאותו Supabase ונראה באותו דשבורד, ומציג רק את המקצוע שנבחר.

## איך מעדכנים

הריפו הזה מכיל **רק את התוצר**. הקוד נמצא בפרויקט Master Evaluator:

```
PYTHONUTF8=1 python build_game_core8.py           # מתוך Question Bank\
PYTHONUTF8=1 python publish.py --core8 --single   # מתוך Game\
```
